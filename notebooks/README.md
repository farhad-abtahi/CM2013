# Book demo notebooks

One notebook per chapter (`ch01`–`ch16`) that reproduces the textbook's figures and
worked examples, plus one `track_*.ipynb` per capstone track that walks the full
pipeline on real data. These are **read-and-run**: every cell already works, nothing
to fill in — for the fill-the-gap exercises, see [`../labs/`](../labs/).

Every notebook carries three badges (Colab / nbviewer / JupyterLite) in its first
cell — see the [notebook gallery](https://farhad-abtahi.github.io/CM2013/) to browse
all of them at once, searchable and filterable.

Track notebooks (`track_*.ipynb`) download their real dataset directly from the
original source on first run — nothing is bundled here. See
[`../tracks/README.md`](../tracks/README.md) and each track's dataset card for
license and source.

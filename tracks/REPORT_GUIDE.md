# Writing the capstone report

Write the report as you would a short scientific paper about your own project: what problem you
tackled, what you did and why, what came out, and how far the result can be trusted. It is graded
together with your code and presentation ([`CAPSTONE_REPORT_RUBRIC.md`](CAPSTONE_REPORT_RUBRIC.md)).

## Format

| | |
|---|---|
| **Length** | At most **20 pages**, including figures and tables. References and appendices do not count. |
| **File** | One PDF, submitted with `predictions.csv` in the Canvas assignment *Capstone Project Report & Predictions* |
| **Deadline** | Thu 10 Dec 2026 |
| **Language** | English |
| **Layout** | Any readable template, 11–12 pt, numbered figures and tables, page numbers |
| **Code** | Don't paste code. Give the repository link and the commit of your final model. |

Twenty pages is a limit, not a target. The appendix is optional reading, so keep everything that matters in the main text.

## Structure

Use the usual structure of a scientific paper: **Introduction, Methods, Results, Discussion**, plus
references. How you divide it further is up to you. At the end, add a short **Contributions** section
with one line per team member.

Write about *your* project: the choices you actually faced, what you tried, what surprised you, and
what you would do differently.
